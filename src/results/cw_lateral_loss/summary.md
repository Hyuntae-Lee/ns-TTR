## 4. 읽는 법

* 납품값은 위상 기반 유리 껍질 TLM 역산의 k_eff 하나다. 나머지(스텝 절편, Parker, 양면 온도차)는 같은 이웃의 기준 via 와 비교하는 상대 void 지표이며, 절대값(겉보기 α·ρc)은 유리로 새는 열 때문에 체계적으로 편향된다: 절편·Parker 는 겉보기 상승이 빨라져 **높게**, 단열 TLM 은 진폭이 줄어 **낮게** 읽는다 (결정 2026-10-22: 핀 모델은 제거, 양면 온도차는 k_eff 를 내지 않음).
* 유리 껍질 어드미턴스 TLM 모델(실린더 주위 무한 유리 해석해)은 모든 경계·피치에서 참값의 ±2 % 안에 든다: 락인 주파수(10 Hz 이상)의 유리 침투 깊이가 이웃까지의 간격과 비슷하거나 짧아 경계가 거의 보이지 않기 때문이다. 유일하게 배열 정보 없이 쓸 수 있는 방법이다.
* 간격 50 µm 의 이웃 단열 셀에서는 얇은 유리 고리가 빨리 포화되어 병렬 열용량처럼 작용 → 절편·Parker 의 편향 부호가 뒤집힌다 (절편 −27 %, Parker −5 %). 폐쇄 경계의 DC 는 무한히 올라가므로(ΔT_far 5 K) 이 경계는 상한일 뿐 물리적 값이 아니다.
* void 에 의한 변화는 납품값과 과도응답 지표에서 거의 같고(r_half 20 µm: −1.5 %, 35 µm: −8.6 %) 경계에 둔감하다: void 는 축방향 직렬 저항으로 작용하고 측면 손실 편향은 대부분 상쇄된다. 양면 온도차 R_th 는 로드 중앙 void 에 대해 약 절반만 반응한다: 이 지표의 감도는 void 평면을 지나는 flux ∝ 1 − z/L 로 펌프면에서 반대면으로 갈수록 선형으로 줄어든다.
* 양면 온도차는 단열 로드에서 정상상태가 없어 R_th 가 L/(2kA)+스프레딩 저항으로 수렴한다 (통과 흐름의 L/(kA) 가 아님).
* §3 의 폭이 '측정값이 via 가 아니라 배열(이웃)에 얼마나 지배되는가' 의 지표다. 폭이 작은 방법이 배열 정보 없이 쓸 수 있는 방법이다.
* 스펙 §3 의 '방법 간 불일치 = void 지표' 는 여기서 양면 온도차 ↔ 과도응답 지표의 차이로 나타난다 (α 로 읽는 지표는 void 를 깊이와 무관하게, R_th 는 깊이에 비례해 줄어든 만큼만 본다).
