# CW 열전도도 측정 모드 — 스펙 (초안 v0.2, 2026-10-20)

## 0. 요약

새 주문: CW 레이저로 TGV 비아를 가열하고 비아의 **유효 열전도도 k_eff** 를 뽑는 기능.
"자기발열(steady-state, ΔT/P → R_th) + 레이저 플래시(과도응답 → α)" 의 조합.

확인된 측정 구성:
- 펌프: 비아 **바닥면**, CW 532 nm, **플랫 타원 스팟 12 × 10 µm(지름)** ≪ 비아 80 µm → 이웃 비아는 가열되지 않음
- 프로브: 윗면 / 바닥면 / 양면 — 세 구성을 모두 시뮬레이션으로 비교. 프로브 스팟 **8 µm(지름)**, 양면 동일
- 시편: 기판이 **공중에 떠 있음** — 상하면 공기, 열은 유리를 통해서만 빠짐. 유리 두께 = 비아 길이 = 500 µm
- 펌프 출력 P: GUI 입력 (출력 밀도·펌프면 국소 상승을 같이 표시해 선형 영역 판단)
- 기존 반사형(ns 펄스) 모드는 그대로 보존. 같은 저장소, 코어(`ttr_sim`) 공유, GUI 분리(`app_cw.py`)

## 1. 물리적 결론 (설계 전제)

수치는 ⌀80 × 500 µm Cu(k=398, ρc=3.45 MJ/m³K, α=1.15e-4) / fused silica(k=1.38, ρc=1.63 MJ/m³K, α=8.5e-7) 기준.

| 항목 | 값 | 의미 |
|---|---|---|
| 비아 축방향 열저항 L/(kA) | ≈ 250 K/W | 흡수 1 mW 당 0.25 K |
| 축방향 통과 시간 L²/α | ≈ 2.2 ms | 비아가 축방향으로 평형하는 시간 |
| 투과 신호 반상승 (펄스, Parker) 0.1388·L²/α | ≈ 0.30 ms | |
| 투과 신호 선형 점근 절편 (스텝) L²/(6α) | ≈ 0.36 ms | CW 스텝 입력의 Parker 대응식 |
| Cu 내 반경 평형 R²/α | ≈ 14 µs | 펌프 스팟 크기·형상은 투과 신호에 거의 안 보임 |
| 플랫 스팟 스프레딩 저항 ≈ 1/(4·k·a), a=5.5 µm | ≈ 115 K/W | 펌프면 프로브 신호는 스팟에 민감. 장단축비 1.2 → 등가 원형 대비 수 % |
| 펌프면 출력 밀도 (플랫 12×10, 흡수 10 mW) | ≈ 1e8 W/m², 국소 상승 ≈ 1 K | 선형 영역 한계는 여기서 먼저 걸림 |
| 상하면 공기 대류 h·A (h=10) | ≈ 5e-8 W/K | 비아 컨덕턴스(4e-3)의 1e-5 → **단열 처리** |
| 유리 껍질 열용량 / Cu 비아 열용량, δ=√(α_g t) | t=0.3 ms: ~0.4 / t=2 ms: ~1.0 (상한) | **ms 영역에서 유리는 단열재가 아님** |
| 유리 열침투 깊이 μ_g=√(α_g/πf) | 10 Hz: 164 µm / 100 Hz: 52 µm / 1 kHz: 16 µm | 락인 주파수 vs 피치 |
| 유리 간격 d 를 열이 건너는 시간 d²/α_g | 50 µm: 3 ms / 100 µm: 12 ms / 200 µm: 47 ms | 이웃 비아 싱크 평형이 생기는 시각 |

따라서:
1. **DC 평형은 존재하지 않는다.** 떠 있는 기판에서 열은 유리판 안을 2-D로 퍼지기만 하고(log 발산), 결국 이웃 Cu 비아(차가운 싱크)로 들어간다. 윗면 곡선은 계단형: 열 도달(~0.3 ms) → 비아 축방향 평형 어깨(~2 ms) → 유리로 새며 log 크리프 → 이웃 비아 싱크 평형(피치에 따라 10~50 ms) → 기판 전체 서서히 데워짐(초 단위). "자기발열 평형값" 정의는 그대로 쓸 수 없고, (a) 과도응답, (b) 특정 시각의 양면 온도차, (c) 락인 진폭·위상 으로 대체.
2. **Parker 식은 측면 단열 가정이라 그대로 못 쓴다.** 측면 유리 손실이 ms 영역에서 Cu 열용량과 맞먹으므로 모델 기반 보정/피팅이 필요 — 시뮬레이터가 그 모델이다.
3. **투과(바닥 펌프 → 윗면 프로브) 신호는 void 깊이에 무관하게 모든 void를 직렬 저항으로 본다.** 위치 정보는 잃지만 깊은 void도 놓치지 않음 — 기존 반사 모드(깊이 정보 있음, 깊은 void 약함)와 상호보완.
4. 선형 영역(mW 급, ΔT ≪ 1 K)이므로 시스템은 LTI: **스텝 응답 하나에서 임펄스 응답, 임의 chopping 응답, 락인 진폭·위상을 후처리로 모두 얻는다.** 실제 장비는 SNR 때문에 락인을 쓰겠지만 시뮬레이터에서는 재계산 불필요.

## 2. 모델

### 2.1 좌표·경계
- z = 0: **펌프 면** (열원). z = L: 반대 면. 둘 다 단열 (공기). `BottomStack` 비활성.
- r ≤ R_cu: Cu, R_cu < r ≤ R_out: 실리카.
- 외곽 경계 옵션 (DC/저주파 부분만 영향):
  - `far`: 큰 R_out + 단열 — 열이 경계에 닿기 전까지만 유효 (기존 `√(D·t) < 0.8 L` 식 경고와 같은 방식으로 `√(α_g t) < 0.8·(R_out − R_cu)` 경고)
  - `neighbor_sink`: r = pitch − R_cu 에 등온(실온) 경계 — 이웃 비아를 완전 싱크로 보는 **하한**
  - `neighbor_adiabatic`: r = pitch/2 단열 — **상한**. 둘 사이에 진실이 있고, 차이의 크기가 "DC 값이 경계에 얼마나 지배되는가"의 지표.
  - 이웃 비아를 이산적 Cu 기둥으로 넣는 3D 는 범위 밖 (필요 시 `solver3d` 확장).

### 2.2 열원
- CW 스텝: P [W], f(t)=1 (t ≥ 0). 흡수 = P·(1−R). `Laser` 에 `mode="cw"` / `power` 추가 (기존 `energy`/`tau_p` 경로와 공존, `I0 = P/beam_area`).
- 스팟: 플랫 타원 12 × 10 µm(지름). 1차는 **등가 원형 플랫** 반경 a = √(6·5) ≈ 5.5 µm 로 축대칭 계산 (기존 `beam="flat"` 경로). 타원 스팟은 축대칭이 깨지므로 펌프면 프로브 정밀도가 필요해질 때 `solver3d` 에 θ 의존 열원 추가 (2차).
- 정렬 오차(스팟 off-center)는 2차.

### 2.3 프로브
- z = 0 면과 z = L 면 각각에 가우시안 가중치, 1/e² 반경 4 µm (지름 8 µm). 출력: ΔT_pump(t), ΔT_far(t), ΔR/R 각각.
- 세 구성(윗면/바닥/양면)은 결과 선택일 뿐 계산은 한 번.

### 2.4 시간
- 기존 CN 적분기 + Δt 성장. 관측창 기본 20 ms (L²/α 의 ~10배). 스냅샷/곡선은 후처리 FFT 가 가능하도록 충분히 조밀하게 저장.
- **주파수 영역 직접 풀이** 추가: (A + iωC)·T̂ = b 를 주파수마다 한 번씩 복소 희소 풀이 → 락인 진폭·위상의 정확해. 스텝 응답에서 유도한 값과 교차 검증 (시간 적분기의 검증 항목이 됨).

### 2.5 void
- 기존 `VoidSpec` 그대로 (깊이는 펌프 면 z=0 기준으로 명시). 다중 void, 3D off-axis 도 기존 경로 재사용.

## 3. 분석 모듈 (`ttr_sim/analysis.py`)

솔버와 분리된 **순수 함수**. 입력 `(t, ΔT_far, ΔT_pump, P_abs, L, A, ρc, …)`. 같은 함수를 나중에 실측 곡선에도 적용.

| 방법 | 입력 | 출력 | 비고 |
|---|---|---|---|
| 스텝 절편법 | ΔT_far(t) 선형 점근의 t 절편 | α = L²/(6·t_int) | CW 스텝의 Parker 대응. 측면 손실로 편향 → 모델 보정 |
| Parker (임펄스) | 스텝 응답 미분 → t½ | α = 0.1388·L²/t½ | 동일 편향 |
| 양면 온도차 | ΔT_pump(t*) − ΔT_far(t*) | R_th(t*) → k_eff = L/(R_th·A) | t* 선택 필요, 준정상 창에서 서서히 drift |
| 락인 | 선택 f 의 진폭·위상 | TLM(ABCD) 역산 | 스텝 응답 FFT 또는 2.4 직접 풀이 |
| 곡선 피팅 | 곡선 전체 | k_eff (+ 측면 누설 G′) 최소자승 | 가장 강건. 1-D 핀 모델 또는 FV 모델 자체 |
| 기준 비교 | baseline vs void 결과 | 각 방법의 Δ | 방법 간 불일치 자체가 void 지표 (α·ρc ≠ k_eff(R_th)) |

GUI: 한 번의 계산 결과 위에서 분석 방법을 드롭다운으로 전환.

## 5. 검증 항목
1. 균질 Cu·측면 단열(`far`, 짧은 창)에서 ΔT_far(t) 가 1-D 상수-flux 해석해(Carslaw–Jaeger)와 일치, 절편 L²/(6α) 재현
2. 주파수 영역 직접 풀이 vs 스텝 응답 FFT — 진폭·위상 일치
3. 에너지 보존 (흡수 = Cu 저장 + 실리카 저장 + 싱크 방출)
4. 격자/시간 수렴
5. 측면 손실 민감도: `far` vs `neighbor_sink` vs `neighbor_adiabatic` 로 각 분석 방법의 k_eff 편향 정량화 — **첫 번째 스터디**

## 6. 입력 파라미터

확정 (기본값):
- 펌프 스팟: 플랫, 타원 12 × 10 µm 지름 → 1차 등가 원형 반경 5.5 µm
- 프로브 스팟: 지름 8 µm (1/e² 반경 4 µm), 펌프면·반대면 동일
- 유리 두께 = 비아 길이 = 500 µm
- 펌프 출력 P: GUI 입력 (기본 10 mW 가정, 출력 밀도·펌프면 국소 상승 표시)

미확정 (GUI 파라미터, 기본값 임시):
- 비아 피치 및 배열(정방/육방) — 외곽 경계 옵션 `neighbor_*` 에 필요
- 바닥면 Cu 반사율(CMP 후) — 기본 0.6
